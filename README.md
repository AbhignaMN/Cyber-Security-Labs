# Security Labs

Hands-on practice for application security and VAPT, done in my own
Kali Linux lab and on authorised targets only (my own VM, scanme.nmap.org,
OWASP Juice Shop, TryHackMe).

| Lab | What's inside | Status |
|-----|---------------|--------|
| [Nmap](nmap/) | Scan types, service/version detection, NSE scripts, findings on scanme.nmap.org | Done |
| [Juice Shop](juice-shop/) | Pentest write-up: 6 findings — SQLi, IDOR, JWT data exposure, weak password / no rate limiting, client-side validation bypass, DOM XSS | Done |
| [Burp Suite](burp-suite/) | Proxy, Intercept, Repeater, Decoder, Intruder — notes, screenshots and problems solved | Done |
| Metasploit | TryHackMe exploitation rooms | In progress |

## Skills practised
- **Recon:** Nmap port scanning, service and OS detection, NSE scripts
- **Web testing:** OWASP Top 10 — injection, broken access control, XSS, authentication flaws
- **Tools:** Burp Suite, Docker, curl, bash scripting, Git
- **Reporting:** vulnerability write-ups with steps, impact and fixes
